第二章 设计哲学：四个目标一张桌子

报告最有方法论价值的部分在开头。Qwen 明确提出：任何架构改动同时触碰三件事，必须放在同一个设计问题里联合评估。

  1. 能力轴：训练 loss 加下游 benchmark。
  2. 成本轴：该改动在训练、Prefill、Decode 三个阶段各自的代价。
  3. 稳定轴：对最优超参数和大规模训练稳定性的影响。

报告中反复强调一个观察：loss 与下游表现经常不同步。全篇有至少四个案例（详见第九章），其中既有「loss 单调下降但下游饱和」（N-gram 词表），也有「loss 几乎不动但 benchmark 明显受益」（GR 的动态门控）。这直接决定了他们的实验纪律：任何候选改动都要三轴齐看，只看 loss 会做出错误决策。

第三章 架构升级之一：GDN + QSA 混合注意力

3.1 问题：长上下文下注意力的两笔账

全注意力（Full Attention）随序列变长有两笔成本：计算量 O(n²)，KV Cache 随生成长度线性膨胀。滑窗注意力（SWA）省了计算，但窗口外的信息只能靠层间逐层传递，丢失精确检索能力。

Qwen 的解法延续 Qwen3.5 以来的 Hybrid 路线：每 4 层中 3 层用 GDN，1 层保留全局注意力。GDN 负责把历史压缩进固定大小的循环状态（高效「记住」），周期性出现的全局注意力负责精确「回看」。

3.2 GDN（Gated DeltaNet）：会擦除的线性注意力

直觉理解：普通线性注意力把历史 key-value 累加进一个矩阵状态，信息只增不减，相似 key 会无限叠加。GDN 引入 delta rule，写入前先估计该 key 已关联的旧值，只写「残差」：

  • 衰减门 αt ∈ (0,1)：控制历史状态整体保留多久（遗忘门）。
  • 写入门 βt ∈ (0,1)：控制新信息写入强度。
  • 状态更新等价于 St = αt (I − βt kt kt^T) St−1 + βt kt vt^T，即「先定向擦除，再写入」，相似 key 更新已有关联而非累加。

工程细节锚点：q/k 经短因果卷积加 L2 归一化；输出门用 sigmoid（相对原版 GDN 的 SiLU 门有一致提升）；全程 Zero-Centered RMSNorm。配套内核库 FlashQLA（TileLang 实现）相对 FLA Triton 内核前向提速 2 至 3 倍、反向约 2 倍，已开源。

3.4 一个被及时拦住的错误：NoPE 陷阱

报告提到全局注意力层保留 RoPE 的原因：预训练阶段去掉位置编码（NoPE）与保留 RoPE 几乎无差别，但后训练后 NoPE 变体的「无休止生成」率显著升高，模型更容易停不下来。这是「预训练指标一致、后期评估分叉」的第一个案例，也是他们坚持联合评估的直接理由。

3.5 QSA（Qwen Sparse Attention）：把「找重要上下文」本身也变便宜

动机：DeepSeek 的 DSA 已证明轻量 indexer 加 token 级稀疏掩码能大幅提速，但 indexer 本身是 O(n²)，序列越长，「找重要内容」的开销越不可忽视。QSA 的思路：先在压缩后的粗粒度上找，再对选中的区域精确算。

工作机制（四步）：

  1. 分块压缩：key 序列按 r=4 个 token 一块做平均池化，得到 micro-block 表示；先压缩再加 Partial RoPE（128 维中 64 维加旋转），避免对不同旋转相位的 token 表示取平均。
  2. 轻量打分：indexer 是一个 MQA（4 个 query 头 + 1 个共享 key 头），对每个 query 与所有 block 算 ReLU 内积并跨头求和，带 block 级因果掩码（只能给完整可见的块打分）。
  3. Top-K 选择：token 预算 K=2048，即每 query 最多选 512 个完整块，末尾不足一块的尾部 token 恒保留。
  4. 稀疏注意力：只对选中块展开后的 token 集合做核心注意力。

与跨层共享索引的 IndexShare 路线对比，QSA 每层独立压缩，不依赖跨层注意力相似性，恰好适配 GDN 与注意力层交错的 Hybrid 架构。消融显示：达到全注意力基线时 QSA 的 indexer 相对延迟可压到 0.25，IndexShare 在 0.5 时仍低于基线。

两阶段训练（CPT 阶段引入，序列长 256K）：

  • Stage 1 稠密蒸馏：把主干全注意力的 token 级分布（全体教师头求和、L1 归一、max pooling 对齐到块级）蒸馏进 indexer，只训 indexer 1,000 步，约 2B tokens。
  • Stage 2 稀疏训练：主干与 indexer 联合训练 8,000 步，约 200B tokens，KL 损失只在 Top-K 块上计算。训练期实现了一个融合内核，联合计算稀疏注意力输出与 KL 损失，不落中间结果。

结果：QSA 与全注意力的训练 loss 曲线几乎重合，整体 loss 差在 10⁻⁴ 量级。

第四章 架构升级之二：Gated Residual（GR）

4.1 问题：一条残差流的信息稀释

Pre-norm Transformer 所有层共用一条残差流，早期写入的特征要与其后所有写入竞争，层数越深稀释越严重。既有工作分两族：让每层读写更灵活（Highway 一脉），或把残差流加宽成多分支（AltUp、Hyper-Connections 一脉）。Qwen 的结论是两件事互补：加宽提供容量，读写机制决定容量怎么花。

4.2 关键消融发现（报告 Table 5，25B-A3B、560B tokens）

残差设计Loss九项基准平均
Pre-norm 基线1.61750.91
mHC（静态算子）1.59652.49
mHC（动态算子）1.59454.47
GR1.59054.66

五点设计结论：

  1. 仅加宽就值 1.58 分：静态多分支相对基线的提升，几乎不花计算，只多付访存。
  2. 动态化再值 1.98 分：loss 只差 0.002，benchmark 差距却很大，这是「loss 会低估改动价值」的典型案例。
  3. 读的粒度比写重要：读门细化到逐通道（elementwise）有收益；写门保持每分支一个标量即可。
  4. 从全部分支预测算子，且对各分支分别归一化（group RMSNorm）更好。
  5. 分支混合算子 Hres 可以删掉：读写足够灵活后，nr×nr 的分支混合无显著收益，删掉还省去每块一次完整残差读取，这是推理侧最大的访存项。

4.3 GR 的最终形态

  • 4 条并行分支，注意力块与 MLP 块各配一套 GR。
  • 读：各分支独立 RMSNorm，经低秩瓶颈（rank = d/8）预测逐元素 sigmoid 门，加权平均成块输入。这一步同时替代了 pre-norm，加宽不增加归一化层。
  • 写：块输出按每分支一个数据相关标量门（2σ 缩放）写回所有分支。
  • GR 与团队此前的 GatedNorm 工作天然同构，直接合并为一个算子；标准随机初始化即可，静态项无收益。

与同族工作的差异定位：HC/mHC 把容量花在 Hres 上，VWN 把嵌入切窄追求细粒度读写，GR 把表达力集中花在「读」上。

4.4 分支用途分析：模型自己学会了分工

由于删掉了分支混合，每条分支是纯粹的累加器，可以精确分解每个块读取的信息来源。对 20 层 GR 模型与无 GR 参照模型对比（780 条有向路径）：

  • 一条分支涌现为长程通道：连接第 0 层与大量中后层，典型跨距 10.9 层（其余三条为 3.4 至 3.9 层），主要把早期 GDN 输出跨越深度送达 softmax 注意力层。第 0 层 GDN 到第 15 层注意力的输入份额从参照模型的 0.020 升至 0.138。
  • 全局注意力层是长程信息的枢纽：读 GR 分支最重的子层基本都是注意力层，印证了「GDN 压缩掉的历史由注意力层显式回补」的分工。
  • 路径分布整体变化：相邻层路径与超远程（跨 12 层以上）路径份额分别净增 0.96 与 0.91，中程路径净减 3.21。GR 的策略是筛选少数路径并放大。

4.5 推理效率与第二个被拦住的错误

  • Sparse write 失败：训练后每个 GR 层的写入通常集中在两个分支，于是尝试每块只读门值最高的两条分支。预训练 loss 与基准几乎无损，但后训练质量明显退化，放弃。报告原话级别的重要提醒：只看预训练指标会导向错误决策。
  • FP8 残差状态：GR、门控注意力、GDN 的门都约束了写入幅度，残差值分布很窄，天然适合低精度。FP8 存储使残差访存字节数相对 BF16 减半，质量几乎无损。
  • 读写各融合为单一内核，加宽流每块每方向只遍历一次。

第五章 架构升级之三：N-gram Embedding

5.1 思路

受 Gemma 3n Per-Layer Embedding 与 DeepSeek Engram 启发：普通 Embedding 按单 token 查表，N-gram Embedding 用当前 token 与前若干 token 组成的局部上下文查表，为常见短语搭配提供额外表示。核心吸引力是「加参数几乎不加每 token 计算」，且查询位置可提前确定，表可以放 Host Memory 异步预取，与第一层计算重叠，不长期占显存。

5.2 三组消融结论

  1. 放哪层：固定参数预算下扫了第 1 至 25 层与双层组合，无一致的深度优势，分散到多层无收益。最终只放一层，选第 2 层，便于预取与第 1 层计算重叠。
  2. 固定总参数预算下与 MoE 抢参数（减专家补 N-gram）：loss 在 10 倍词表（占 25% 参数）处最优，但下游基准相对纯 MoE 基线无清晰提升。结论：N-gram Embedding 与 MoE 专家在扩容中扮演不同角色，不能互相替代。
  3. 放开预算纯加词表（20× 到 200×）：loss 单调下降，下游收益饱和甚至波动；中文基准（C-Eval、CMMLU）随词表持续变好。这是「loss 与下游背离」的第三个案例，也解释了为什么报告坚持两轴都看。

最终配置：51B 参数、单层、置于 Layer 2。词表压缩、按 n-gram 阶数非均匀分配、按频率分区等参数效率技巧在其训练配方下均无一致收益。

第六章 架构升级之四：Muon 优化器与 Scaling Law

6.1 Muon 怎么用：三个决定性实现选择

  1. 正交化精度：Newton-Schulz 迭代取 8 步（更少步数会在压力测试中出现更多梯度尖峰），采用 Polar Express 的逐步系数表；动量 μ=0.95 Nesterov；更新按 0.2·√max(A,B) 缩放使 RMS 与矩阵形状无关。
  2. 参数分工：真正充当二维线性映射的权重（注意力 q/k/v/o、GDN 输入输出投影、专家 fc1/fc2、N-gram 的 key/value 投影）用 Muon；输入输出 Embedding、输出头、MoE Router、GR 低秩投影留在 AdamW。Router 用 Muon 会加剧早期波动且无收益，报告给出的解释是 router 各输出维度对应各专家分数、维度间近似独立，没有可供正交化利用的共享线性结构。N-gram 表用 Adam 且关 weight decay。
  3. 融合矩阵先拆再正交：Megatron 里 QKV、SwiGLU fc1、GDN 输入投影是融合存储的，直接对融合矩阵做 NS 会把无关子块的奇异方向混在一起，且缩放系数按拼接形状计算出错。拆分粒度：QKV 与 GDN 输入投影按头拆（loss 与基准双升），fc1 拆 gate 与 up 两半（基准微升）。拆分还提供了按子矩阵排除 Muon 的自然粒度（GDN 的 decay/beta 投影是逐头标量，正交化无意义）。

6.2 工程配套

  • NS 迭代要求对每个完整矩阵整体更新，与 Megatron 的 TP/DP 切分冲突。Qwen 自研 Canzona：逻辑优化器分配与物理参数布局解耦，α-balanced 静态分区器按估计 NS FLOPs 在 DP rank 间均衡整参数分配，异步 Micro-Group 流水线经融合 All-to-All 在 TP rank 间重建矩阵，同时保住 ZeRO-1 的 bucket 几何与 Reduce-Scatter 重叠。
  • 拆分后每层产生上百个小矩阵，优化器 step 变成大量小内核，启动开销主导，整步捕获进 CUDA Graph 消除。

6.3 重拟合 Scaling Law：更大胆的超参数

新架构加新优化器使最优超参数整体上移，Qwen 重新拟合了 scaling law 并分别验证两个预测：

验证项设置结果
Batch size10.8B-A0.89B MoE，4T tokens新预测 B=25.2M 比旧配方 B=12.6M 降 loss 7.2×10⁻³；再放大 1.5 倍仅劣化 4.3×10⁻⁴。曲线下陡上平，预测接近最优

Batch-size warmup 被证伪：从 6.3M 渐进爬到 25.2M 的两个变体都不优于直接用目标 batch 起步，反而多耗 18.8% optimizer steps。机制上，warmup 早期小 batch 的高梯度噪声抬高 loss，中期靠步数积累短暂反超，学习率衰减后优势被中和，最终恒定大 batch 胜出。生产训练直接从目标 batch size 开始。

第七章 训练稳定性：压力测试驱动设计

7.1 方法

大规模不稳定性可通过在中等规模上抬高学习率复现（Wortsman et al., 2023）。测试设计：恒定学习率（绕过衰减，模拟生产训练的峰值平台期），28 层 25B-A3B，2× 与 4× 最优学习率，监测 loss spike 率、p99.9 梯度范数、最大激活值。通过标准：新配方至少与已被规模化验证的旧配方同等稳定。

7.2 结果

压力档位AdamW + 旧结构Muon + 旧结构Muon + GR
2× 最优 LR4.3 spikes/万步0.20.2
4× 最优 LR183 spikes/万步，213/19932 步触发裁剪零裁剪触发零 loss spike

单变量归因（3× LR，仅切换 GatedNorm）：spike 率从 32.0 降到 3.2/万步，裁剪触发从 256 降到 20。激活 outlier 随学习率近比例增长，spike 率增长更快；开启门控后，最高学习率下的 outlier 水平低于基线最低学习率。报告给出的机制解释：高学习率训练需要 rescaling 机制，没有显式门控时网络靠激活 outlier 自发实现 rescaling，因而脆弱；乘性门直接提供 rescaling，训练因而稳定。

生产验证（同数据序、同调度、同优化器，前 276B tokens）：加 GR 降 loss 0.026，完整 Flash-Next 配方再降 0.032，合计 0.058；GR 使梯度范数 p99.9 降至 Muon 基线的约 1/4，滑动窗口标准差降 4.3 至 4.7 倍；全量训练全程无一次 loss spike 与梯度范数异常，且未依赖 qk-clip、SwiGLU-clip 等显式裁剪手段。

9.2 架构、效率、优化是一个耦合系统

GR 提供 rescaling 带来稳定裕度，稳定裕度把最优学习率与 batch size 上移，上移又改善吞吐与收敛；分阶段成本核算（训练 / Prefill / Decode）决定了稀疏注意力向 indexer 要效率、GR 把表达力集中在读侧。抽掉任何一个轴，都会放进看似无害的捷径。

9.3 对行业竞争格局的含义

这份报告回答的问题从「谁的模型更大」换成「获得一单位有效智能需要多少计算」。低价（输入 ¥1/百万 tokens）是架构层面成本结构的结果：少激活参数省训练、稀疏注意力省长上下文无效计算、N-gram 表把容量挪到更便宜的存储层级、FP8 残差与融合内核压访存、Muon 加新 scaling law 继续挖训练效率。报告也坦承边界：结论主要覆盖架构与训练效率，真实业务成本还受硬件、系统实现、流量结构影响。

9.4 局限与开放问题

  • Base 对比主要对手是自家两代模型，跨厂商 base 级对比缺失。
  • CoWorkBench、RecreationBench、ClawEval-MM 等为内部或新基准，外部复现口径待建立。
  • 报告自评当前最紧的瓶颈是评估吞吐：缺少能可靠预测后训练排序的廉价中规模探针，设计空间搜索受限。
  • N-gram 词表的中文基准持续受益现象未给机制解释。
