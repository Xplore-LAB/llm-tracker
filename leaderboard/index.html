⚖️ 先读口径：为什么这里有两个榜，而不是一个总分 AA Intelligence Index 由 Artificial Analysis 用同一套 9 项评测独立跑测，衡量的是实际能力；Arena Elo 来自人类盲测投票，衡量的是主观偏好。两者衡量不同维度，同一模型排名可能天差地别（Claude Opus 5 在能力榜第 1，在偏好榜仅第 12），所以本页拒绝把它们加权成单一总分。厂商官方自测分各自使用不同 harness（Claude Code / Kimi Code / DeepSeek Harness 等），横向不可相减，因此只出现在单模型详情里，不进入对比表。
