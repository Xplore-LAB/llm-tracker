📌 它是什么

DGX Spark 是 NVIDIA 面向个人开发者的桌面级 AI 计算机，2025 年 1 月以 Project DIGITS 之名发布，2025 年 10 月中旬正式开卖。它把 GB10 Grace Blackwell 超级芯片、128GB CPU 与 GPU 一致性统一内存、ConnectX-7 200Gb/s 网卡和完整 NVIDIA AI 软件栈，装进一个与 Mac mini 相仿、约 1 升体积、重约 1.18 kg 的盒子里。

官方定位很明确：这不是游戏 PC，也不是数据中心替代品，而是「把 AI 开发平台放回桌面」的设备。原型开发、开源大模型微调、本地推理、边缘与机器人应用预研，是它的四个主场景。交付当天，黄仁勋把首台机器亲手交给马斯克，呼应 2016 年首台 DGX-1 的交接。

🎯 能干什么

  • 本地推理大模型：NVFP4 格式下，单机可装入最高约 200B 参数的模型。
  • 微调开源模型：官方口径支持最高约 70B 参数模型的微调（LoRA 类高效方法）。
  • 双机互联：两台通过 ConnectX-7 互联，可把最高约 405B 参数的模型分摊到两颗 GB10 上运行。
  • AI 原型开发：NIM、CUDA、PyTorch 全家桶开箱即用，适合本地快速迭代与验证。
  • 边缘与机器人预研：Isaac 机器人、Metropolis 智慧城市应用的开发跳板（正式部署另有 Jetson 系列）。

🧮 带宽账本：273 GB/s 意味着什么

这台机器最大的争议点不在算力，而在内存带宽。128GB 统一内存解决了「装得下」的问题，但 LPDDR5x 的 273 GB/s 决定了「跑不快」的上限。推理 decode 阶段每生成一个 token 都要把全部权重读一遍，理论速度上限可以直接算：

模型规模权重占用理论 decode 上限（273 GB/s ÷ 权重）直观结论
8B（INT4 量化）约 4 至 5GB约 55 至 68 tok/s小模型体验流畅
70B（FP8）约 70GB约 3.9 tok/s能跑但慢，适合离线批处理
200B（FP4）约 100GB约 2.7 tok/s装得下是主要价值，速度别期待
提升 decode 速度的另一条路是换解码范式。Nemotron-Labs-Diffusion 技术报告实测：8B 模型在 DGX Spark 上以扩散并行解码达到 112 tok/s，是自回归基线 41.8 tok/s 的 2.7 倍（w4a16）。这正好印证了「带宽受限场景下，并行解码的收益最大」。

带宽公式与 memory bound 原理见本站「硬件志 · 硬件深挖」章；实测数据来自 Nemotron-Labs-Diffusion 技术报告（arXiv 2607.05722）。

🧭 适合谁，不适合谁

适合

  • 需要在本地完整跑通大模型工作流的算法工程师与研究者
  • 想做 70B 级微调、200B 级推理验证，但不想排队等集群的独立开发者
  • 高校实验室与教学场景：一台机器覆盖从 CUDA 到 NIM 的全栈教学
  • 边缘与机器人应用的预研团队

不适合

  • 追求小模型高并发推理速度的场景（带宽天花板明显，台式 dGPU 更合适）
  • 大模型预训练或大规模多卡训练（它不是干这个的）
  • 游戏与图形创作（没有显示输出取向，也不装 Windows 游戏生态）
  • 只需要聊天级使用的普通用户（云 API 便宜得多）

💰 版本与价格

  • Founders Edition：官方版 $3,999（2025 年 10 月中旬通过 NVIDIA 官网与零售商开售）。CES 发布时曾预告 $3,000，正式发售调价。
  • 合作伙伴版本：华硕、戴尔、惠普、联想、微星、技嘉等厂商基于同一 GB10 平台的定制机型陆续跟进。
